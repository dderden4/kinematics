# Python Kinematics Solver

A Python-based calculator that solves translational and rotational kinematics problems by computing unknown motion variables from user-provided inputs.

## Features

* Solves translational motion problems
* Solves rotational motion problems
* Calculates unknown variables such as:

  * Displacement
  * Velocity
  * Acceleration
  * Time
  * Angular displacement
  * Angular velocity
  * Angular acceleration
* Interactive command-line interface
* Reduces manual equation solving

## Technologies

* Python

## Example Applications

* Introductory physics coursework
* Engineering mechanics problems
* Motion analysis and verification
* Educational demonstrations

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd kinematics-solver
   ```

3. Run the program:

   ```bash
   python main.py
   ```

4. Follow the prompts and enter known variables to calculate the unknown quantity.
